# Derek Wydra Portfolio

Static portfolio site for Derek Wydra.

## Structure

- `index.html` — portfolio content and project sections
- `css/styles.css` — all styling and responsive behavior
- `js/main.js` — small progressive-enhancement script for the footer year and reveal effects
- `images/` — add final screenshots here before launch

No build step or framework is required.

3. Replace the disabled resume button with a link to the PDF.

6. Deploy as a static site through Vercel, Cloudways, GitHub Pages, or any standard web host.

Import `darek3d/derek-portfolio` as a new Vercel project. Because the repository is static HTML/CSS/JS, no framework preset or build command is required; the repository root is the output directory.
